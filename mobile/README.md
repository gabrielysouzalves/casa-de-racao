# Casa de Ração — Aplicativo mobile

Aplicativo React Native com Expo para a equipe da loja.

## Executar

No terminal, a partir da raiz do repositório:

```bash
cd mobile
npm install
npx expo install --fix
npm start
```

O aplicativo mobile fica separado do painel web. A conexão autenticada com a API de pedidos será implementada na etapa seguinte.
